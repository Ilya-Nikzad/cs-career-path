###  Append()
---

What is append()?
append() adds one new item to the end of a list.
It's mainly use for list.

---

# Important Rule — `append()`

- **Type:** list method
- **Call on:** list only
- **Input:** one object/item
- **Syntax:** `my_list.append(item)`
- **Purpose:** adds one item to the end
- **Changes:** original list
- **Returns:** `None`
- **Order:** keeps the added item at the end
- **Duplicates:** allowed
- **Important:** if you append a list, the whole list becomes one item
- **Mental model:** **“Put this one thing at the end.”**
