# `Condition`
---

Conditions let our Python program make decisions.

1. if: Use if when something should happen only when a condition is true.

2. else: Use else for the alternative when the if condition is false.

3. elif: Use elif when there are different conditions to check.

4. Multiple elif: You can have several elif branches and the order matters.

Python checks from top to bottom and stops at the first matching branch.

5. Nested Conditions: A nested condition is a condition inside another condition.

Nested conditions are useful when the second decision only makes sense after the first condition succeeds.

# Important Rule — Conditions
if starts a decision.

elif checks another condition if previous conditions were false.

else handles everything that didn't match.

Python checks if/elif branches top to bottom.

Only the first matching if/elif branch runs.

A nested condition is a condition placed inside another condition.

Indentation determines which code belongs to a condition.
