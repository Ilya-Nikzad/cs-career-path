# `Membership operators`
---

Membership operators answer a simple question: Does this value exist inside this collection?

1 in: returns True when a value exists in a sequence or collection.

2 not in: does the opposite.

3 in: With dictionary check the key only

---

# Important Rule — Membership Operators
---

in → checks whether a value exists in a collection.

not in → checks whether a value does not exist.

With a dictionary, x in dictionary checks its keys.

Membership checks produce True or False.

Don't confuse in with is:

in → membership

is → object identity
