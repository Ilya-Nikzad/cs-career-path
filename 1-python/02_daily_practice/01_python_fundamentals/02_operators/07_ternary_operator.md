# `Ternary Operator`
---

The ternary operator lets you choose between two values based on a condition.

Basic syntax:

value_if_true if condition else value_if_fals

The ternary form is useful when you're choosing one of two values.

Don't use it when the logic becomes complicated or requires many statements.

# Important Rule — Ternary Operator
--- 

Syntax: x if condition else y

The condition comes in the middle.

x is returned when the condition is true.

y is returned when the condition is false.

Best for short, simple two-way choices.

It produces a value that you can assign to a variable.
