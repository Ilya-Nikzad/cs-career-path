# `Logical Operators — 30% Lesson`
---

Logical Operators

Logical operators are used to combine or reverse conditions.

and: Both conditions must be True.

or: At least one condition must be True.

not: Reverses the condition: True ↔ False.

Remember:

AND → Both

OR → One or more

NOT → Reverse


# Important Rule — Logical Operators
--- 

and → all conditions must be True

or → at least one condition must be True

not → reverses a Boolean result

Logical operators are commonly used to build more useful if conditions.

Use parentheses when they make a combined condition easier to understand.
