# `Arithmetic Operators`
---

Arithmetic operators perform mathematical calculations on values

(+ addition, - subtraction, * multiplication, / division, // floor division, % remainder)

/ vs //

This is an important difference:

/ → gives a floating-point result

// → performs floor division and gives the quotient rounded down.

% → Returns the remainder after division.

--- 

# `Important Rule — Arithmetic Operators`
--- 

Type: operators used with numeric values

Purpose: perform mathematical calculations

+ → adds

- → subtracts

* → multiplies

/ → division; produces a floating-point result

// → floor division

% → remainder after division

Important difference: / and // do not produce the same result

Useful pattern: number % 2 == 0 checks whether a number is even

Common mistake: assuming // simply means "normal division without decimals"; it performs floor division

Mental model: / asks “what is the division result?”; // asks “what is the floor-divided result?”; % asks “what is left over?”
