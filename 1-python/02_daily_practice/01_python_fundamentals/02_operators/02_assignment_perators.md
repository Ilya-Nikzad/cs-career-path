# `02_assignment_perators`
---


Assignment operators are used to store or update a variable's value.

Like: 

total = 100

Assignment operators let you update that value more conveniently.

Similarly:

total -= 20   # total = total - 20
total *= 2    # total = total * 2
total /= 2    # total = total / 2
total %= 3    # total = total % 3
total //= 3   # total = total // 3

Take the current value, perform an operation, and assign the new value back.

---

# Important Rule — Assignment Operators
---
= → assign a value
+= → add, then assign
-= → subtract, then assign
*= → multiply, then assign
/= → divide, then assign
%= → remainder, then assign
//= → floor-divide, then assign
The variable is updated in place.
Mental model: “Calculate using the current value, then store the result back


# Extra Note 

repr()

Returns the exact representation of a value,
useful for debugging hidden characters like \n or empty strings ''.

not

Reverses a Boolean condition and is commonly used to check for falsy values.
