## 1 Introduction
Computer: An electronic device that performs tasks according to instructions provided by programs.
- Computers are used in education, business, medicine, entertainment, communication, and many other fields.
- Computers can perform different tasks because they are programmable.
- Program: A set of instructions that a computer follows to perform a task.
- Software: Programs that make computers useful.
- Programmer (Software Developer): A person with the skills to design, create, and test computer programs.
- Computer Programming: The process of creating instructions that tell computers what to do.

---
## 2 Hardware
Hardware: The physical devices and components that make up a computer.

A typical computer system has five major components:
```
1. Central Processing Unit (CPU)
2. Main Memory (RAM)
3. Secondary Storage Devices
4. Input Devices
5. Output Devices
```
### 1: Central Processing Unit (CPU)

The CPU, also called the processor, executes program instructions.
- Performs calculations and basic operations.
- Reads and moves data in memory.
- Compares values.
- Executes instructions provided by programs.
- Modern CPUs are small chips called microprocessors.

The CPU is essential because a computer cannot execute software without it.

### 2: Main Memory (RAM)

Main memory, commonly called Random-Access Memory (RAM), is the computer's temporary working area.
- Stores programs while they are running.
- Stores data being processed by programs.
- Allows the CPU to access data quickly.
- RAM is volatile, meaning its contents are erased when power is turned off.

Read-Only Memory (ROM):
- Stores information that the computer can read but cannot normally modify.
- Is nonvolatile, meaning its contents remain when power is turned off.
- Typically stores important system programs, such as the startup program.

### 3: Secondary Storage Devices
Secondary storage: Stores programs and data for long periods, even when the computer is turned off.
- Programs are stored here and loaded into RAM when needed.
- Important files and records are saved here.
Common Storage Devices
```
1. Hard Disk Drive (HDD): Stores data using magnetic encoding on circular disks.

2. Solid State Drive (SSD): Uses solid-state memory, has no moving parts, and is faster than traditional disk drives.

3. External Drive: Connects through a communication port; useful for backups and transferring data.

4. USB Drive: Uses flash memory to store and transfer data. Also called a memory stick or flash drive.

5. Cloud Storage: Stores data on remote servers accessed through the Internet or a private network.

```
Magnetic Storage: A technology that stores data using magnetic patterns on disks. Used in HDDs.

Memory Chip: A small electronic component that stores data electronically. Used in SSD, USB drives, and memory cards.

Cloud storage allows users to access data from different devices and locations with a network connection.

It can also provide data backups.

### 4: Input Devices

Input: Data collected from people or other devices.

Input device: A component that collects data and sends it to the computer.

```
- Keyboard
- Mouse
- Touchscreen
- Scanner
- Microphone
- Digital camera

```
Disk drives and optical drives can also function as input devices because they retrieve programs and data.


### 5: Output Devices

Output: Data produced by a computer for people or other devices.

Output device: A component that formats and presents computer-generated data.

```
- Monitor
- Printer
```
Disk drives can also function as output devices because they receive data for storage. Like when we save the data
