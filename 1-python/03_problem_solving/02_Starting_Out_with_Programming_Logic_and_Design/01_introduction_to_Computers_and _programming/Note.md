# Introduction to Computers and Programming
---

This chapter establishes the foundation for understanding computers and programming.

Before learning how to design programs, you need to understand what a computer consists of, how it stores information,

how it executes instructions, and what types of software make it useful

---

## Part 1: Core Idea

A computer is an electronic device that processes information by following instructions written in programs.

However, a computer cannot understand human instructions directly. It needs hardware to perform operations,

memory to hold information, binary numbers to represent data, and software to tell it what to do.

The central idea of this chapter is understanding how all these parts work together:

Hardware provides the physical components. Software provides the instructions.

Data provides the information being processed.

Understanding this relationship helps you understand what programming actually does and why programmers create programs.

## Part 2: Detailed Lesson

### 1.1 Introduction to Computers and Programming

1. `What is a computer?`

It's an electronic device that can perform different tasks by following instructions given to it through programs.

2. What does programmable mean?

Being programmable means that a computer can be instructed to perform different tasks by changing the programs it follows

Like:
```
A computer running Microsoft Word helps you write documents.
The same computer running Microsoft PowerPoint helps you create presentations.
```

3. What is a program?

A program is a set of instructions that a computer follows to perform a task.

Like: 
```
calculator program.
Enter: 12+8 = 20

```
The computer does not independently decide to calculate 12 + 8. It follows instructions provided by the program.

4. What is programming?

Programming is the process of creating instructions that tell a computer what to do.

A person who creates computer programs is called a:
- Programmer
- Software developer
Their responsibilities can include:
- Designing programs.
- Writing program instructions.
- Testing programs.
- Identifying and correcting errors.

5. What is Software?

Software is a collection of programs and instructions used by a computer to perform specific tasks.

Like: Windows a Software that manages a computer's hardware and allows users to run programs.

## Important Distinction

Computer – An electronic device that performs tasks.

Program – Instructions that tell a computer what to do.

Programming – The process of creating computer programs.

Programmer – A person who creates computer programs.

Software – A complete program or collection of programs used by a computer.

### 1.2 Hardware

1. `What is hardware?`

Hardware refers to all the physical devices and components that make up a computer.

Physical means that the components are actual devices that can be physically touched.

The chapter identifies five major components of a typical computer system:
```
Central Processing Unit (CPU) - Processes program instructions.
Main Memory (RAM) - Temporarily stores programs and data. volatile
Secondary Storage Devices (Storage) - Stores programs and files for long periods.
Input devices - Collect information.
Output devices - Present information.
```
A computer is not one single device. It is a system of components working together.

2. `Central Processing Unit (CPU)`

The Central Processing Unit (CPU) is the component that actually runs programs.

It is also called the processor

Evolution of CPUs: Early computers had enormous processing components.

Like:

ENIAC was an early programmable electronic computer built in 1945. It occupied a huge amount of physical space.

3. `Main Memory (RAM)`

Main memory is the computer's temporary working area.

It stores:
- Programs while they are running.
- Data that those programs are currently working with.

For example, imagine that you open Microsoft Word and start writing an assignment.

While you are working:
- The Word program is stored in RAM.
- Your currently active document data is stored in RAM.

What is RAM? RAM stands for Random-Access Memory.

It is called random-access memory because the CPU can quickly access data stored at different locations in RAM.

What is volatile memory? RAM is normally volatile memory.

Volatile means that the stored contents are lost when the computer loses power.

4. `ROM: Read-Only Memory`

ROM stands for Read-Only Memory.

It is another type of memory stored in computer chips.

Unlike RAM:
- ROM is nonvolatile.
- Its contents remain when power is turned off.
- It is designed to be read rather than routinely changed through normal operation.

ROM is typically used to store programs important to the computer's operation.

Remember: RAM is the temporary workspace. ROM retains important information without requiring continuous power.

5. `Secondary Storage Devices`

Secondary storage is used to hold programs and data for long periods, even when the computer is turned off.

Like:
```
1.Hard Disk Drives (HDD). An HDD traditionally stores information magnetically on circular disks.
- Stores data magnetically on spinning disks.
- Has moving mechanical parts.
- Generally slower than an SSD.

2.Solid State Drive (SSD): An SSD stores information using solid-state memory.
- Stores data using flash memory.
- Has no moving parts.
- Generally faster than an HDD.

3.USB flash drives.
- USB Flash Drive
- A USB drive is a small portable storage device that connects to a computer's USB port.
- It uses flash memory rather than a traditional spinning disk.

4.Cloud storage.
- Cloud Storage
- Cloud storage means storing data on remote servers through the Internet or a private network.
```

6. `Input Devices`

An input device collects data from people or other devices and sends it to the computer.

Important detail: Disk drives can also act as input devices.

Because the computer retrieves programs and data from storage devices and loads them into memory.

7. `Output Devices`

An output device receives information from the computer and presents it to people or other devices.
