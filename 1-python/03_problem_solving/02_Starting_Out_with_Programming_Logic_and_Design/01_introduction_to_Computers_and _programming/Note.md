# Introduction to Computers and Programming
---

## 1 Introduction
Computer: An electronic device that performs tasks according to instructions provided by programs.
- Computers are used in education, business, medicine, entertainment, communication, and many other fields.
- Computers can perform different tasks because they are programmable.
- Program: A set of instructions that a computer follows to perform a task.
- Software: Programs that make computers useful.
- Programmer (Software Developer): A person with the skills to design, create, and test computer programs.
- Computer Programming: The process of creating instructions that tell computers what to do.

---
## 2 Hardware
Hardware: The physical devices and components that make up a computer.

A typical computer system has five major components:
```
1. Central Processing Unit (CPU)
2. Main Memory (RAM)
3. Secondary Storage Devices
4. Input Devices
5. Output Devices
```
### Central Processing Unit (CPU)

The CPU, also called the processor, executes program instructions.
- Performs calculations and basic operations.
- Reads and moves data in memory.
- Compares values.
- Executes instructions provided by programs.
- Modern CPUs are small chips called microprocessors.

The CPU is essential because a computer cannot execute software without it.
